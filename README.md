# ION DRIFT

Neon asteroids-harvest arcade for **ElbowOS**. Pilot a magenta skiff through a violet well, split drifting ion shards, and chain combos.

Featured account: [x.com/ElbowOS](https://x.com/ElbowOS)

## Play

```bash
python3 -m pip install -r requirements.txt
python3 ion_drift.py
```

- **Arrows / A D** — rotate
- **W / Up** — thrust
- **Space / K** — fire
- **R** — retry after a drift-loss
- **Esc** — quit

Python 3 + pygame. Full-colour neon arcade, not a terminal toy.

## Record a 9:16 reel

```bash
ELBOWOS_RECORD=1 python3 ion_drift.py
# or
python3 ion_drift.py --record
```

Writes `ION_DRIFT_ElbowOS.mp4` — 1080×1920, 15s, 30fps, H.264 yuv420p.
